# [수능 수학] 삼차함수와 합성함수 그래프 추론 문제 완벽 풀이 (2025 대비)

최고차항의 계수가 양수인 삼차함수 f(x)와 함수 g(x)=e^sin \pi x -1에 대하여 실수 전체의 집합에서 정의된 합성함수 h(x)=g(f(x))가 다음 조건을 만족시킬 때, f(2)의 값을 구하는 문제입니다. 전형적인 수능 고난도 '킬러' 문항으로, 여러 개념을 종합적으로 이해하고 적용해야 풀 수 있습니다.

**문제**

> 30. 최고차항의 계수가 양수인 삼차함수 f(x)와
> 함수 g(x)=e^sin \pi x -1에 대하여 실수 전체의 집합에서 정의된
> 합성함수 h(x)=g(f(x))가 다음 조건을 만족시킨다.
>
> (가) 함수 h(x)는 x=0에서 극댓값 0을 갖는다.
>
> (나) 열린구간 (0,3)에서 방정식 h(x)=1의 서로 다른 실근의 개수는 7이다.
>
> f(3)=\tfrac{1}{2}, f'(3)=0일 때, f(2)=\tfrac{q}{p}이다. p+q의 값을 구하시오.
> (단, p와 q는 서로소인 자연수이다.) [4점]

---

### 1. 함수 h(x)와 조건 (가) 분석

- **함수 h(x):**
  `h(x) = g(f(x)) = e^(sin(πf(x))) - 1`

- **조건 (가): 함수 h(x)는 x=0에서 극댓값 0을 갖는다.**
  1.  `h(0) = 0` 이어야 합니다.
      `h(0) = e^(sin(πf(0))) - 1 = 0`
      `e^(sin(πf(0))) = 1`
      `sin(πf(0)) = 0`
      따라서 `πf(0) = nπ` (n은 정수) 이므로, **`f(0)`은 정수**입니다.

  2.  `x=0`에서 극값을 가지므로 `h'(0) = 0` 이어야 합니다.
      `h'(x) = g'(f(x)) * f'(x)`
      `g'(x) = e^(sin(πx)) * cos(πx) * π`
      `h'(x) = [e^(sin(πf(x))) * cos(πf(x)) * π] * f'(x)`
      `h'(0) = [e^(sin(πf(0))) * cos(πf(0)) * π] * f'(0) = 0`
      `f(0)`은 정수이므로 `sin(πf(0))=0`, `cos(πf(0))=±1` 입니다.
      `h'(0) = [e^0 * (±1) * π] * f'(0) = ±π * f'(0) = 0`
      따라서 **`f'(0) = 0`** 입니다.

  3.  `x=0`에서 **극댓값**을 가져야 합니다.
      `f'(0)=0`이므로 `f(x)`는 `x=0`에서 극값을 갖습니다.
      `h(x) = g(f(x))`가 `x=0`에서 극댓값을 가지려면, `f(x)`의 극값 종류와 `g(y)`의 `y=f(0)` 근방에서의 증감 상태가 중요합니다.
      - `f(0) = n` (n은 정수)
      - `g(y)`는 `y=n` 근방에서 `g'(n) = π * cos(nπ) = π * (-1)^n` 의 부호에 따라 증감합니다.
      - `h(x)`가 `x=0`에서 극댓값 0을 가지려면 (`h(x) ≤ h(0) = 0`), 다음 두 경우 중 하나여야 합니다.
        - **(i)** `f(x)`가 `x=0`에서 극대 (`f(x) ≤ n`) 이고, `g(y)`가 `y=n`에서 증가 (`g'(n) > 0`).
        - **(ii)** `f(x)`가 `x=0`에서 극소 (`f(x) ≥ n`) 이고, `g(y)`가 `y=n`에서 감소 (`g'(n) < 0`).

      `f(x)`는 최고차항 계수가 양수인 삼차함수이고, `f'(0)=0`, `f'(3)=0` 이므로 `x=0`에서 극대, `x=3`에서 극소를 갖습니다.
      따라서 **(i)** 경우에 해당하며, `g'(f(0)) > 0` 이어야 합니다.
      `g'(f(0)) = π * (-1)^f(0) > 0` 이므로 `(-1)^f(0) = 1` 입니다.
      결론적으로 **`f(0)`은 짝수**입니다.

### 2. 조건 (나) 분석

- **조건 (나): 열린구간 (0,3)에서 방정식 h(x)=1의 서로 다른 실근의 개수는 7이다.**
  `h(x) = e^(sin(πf(x))) - 1 = 1`
  `e^(sin(πf(x))) = 2`
  `sin(πf(x)) = ln(2)`

  `f(x)`는 구간 `(0, 3)`에서 `f(0)`에서 `f(3)`까지 감소합니다.
  - `f(0) = n` (짝수)
  - `f(3) = 1/2`
  따라서 `x`가 `(0, 3)`에서 변할 때, `f(x)`의 값의 범위는 `(1/2, n)` 입니다.

  우리는 `f(x)`가 특정 값 `y_k`가 될 때마다 실근이 하나씩 생기는 것을 압니다. 여기서 `y_k`는 `sin(πy_k) = ln(2)`를 만족하는 값들입니다.
  `0 < ln(2) < 1` 이므로, `sin(θ) = ln(2)`를 만족하는 `θ`는 각 사분면에 존재합니다.
  `πy = 2kπ + arcsin(ln(2))` 또는 `πy = (2k+1)π - arcsin(ln(2))`
  `δ = arcsin(ln(2))/π` 라고 하면 (`0 < δ < 1/2`), `y`의 해는 다음과 같습니다.
  `y = 2k + δ` 또는 `y = 2k + 1 - δ`

  이 `y` 값들 중, `f(x)`의 범위인 `(1/2, n)`에 포함되는 것의 개수가 7개여야 합니다.
  `y` 값들을 작은 순서대로 나열해 봅시다.
  - `k=0`: `δ` (범위 밖), `1-δ` (범위 안)
  - `k=1`: `2+δ`, `3-δ`
  - `k=2`: `4+δ`, `5-δ`
  - `k=3`: `6+δ`, `7-δ`
  - `k=4`: `8+δ`, ...

  범위 `(1/2, n)`에 속하는 `y` 값 7개는 다음과 같습니다.
  1. `1-δ`
  2. `2+δ`
  3. `3-δ`
  4. `4+δ`
  5. `5-δ`
  6. `6+δ`
  7. `7-δ`

  이 7개의 값이 모두 범위 `(1/2, n)`에 포함되려면, 7번째 값인 `7-δ`는 `n`보다 작아야 하고, 8번째 값인 `8+δ`는 `n`보다 크거나 같아야 합니다.
  `7-δ < n ≤ 8+δ`
  `f(0)=n`은 짝수이므로, 이 부등식을 만족하는 짝수 `n`은 **8** 뿐입니다.
  따라서 **`f(0) = 8`** 입니다.

### 3. f(x) 식 구하기 및 f(2) 계산

이제 `f(x)`에 대한 모든 정보를 얻었습니다.
- `f(x)`는 최고차항 계수가 양수인 삼차함수
- `f'(0) = 0`, `f'(3) = 0`
- `f(0) = 8`, `f(3) = 1/2`

`f'(x) = ax(x-3)` (a는 상수) 로 놓을 수 있습니다.
`f(x) = ∫(ax^2 - 3ax)dx = (a/3)x^3 - (3a/2)x^2 + C`
- `f(0) = 8` 이므로 `C = 8` 입니다.
- `f(3) = 1/2` 이므로
  `(a/3)(27) - (3a/2)(9) + 8 = 1/2`
  `9a - (27a/2) + 8 = 1/2`
  `18a - 27a + 16 = 1`
  `-9a = -15`
  `a = 15/9 = 5/3`

`a > 0` 이므로 최고차항 계수가 양수라는 조건도 만족합니다.
따라서 `f(x)`는 다음과 같습니다.
`f(x) = (5/9)x^3 - (5/2)x^2 + 8`

이제 `f(2)`를 계산합니다.
`f(2) = (5/9)(2)^3 - (5/2)(2)^2 + 8`
`f(2) = (5/9)(8) - (5/2)(4) + 8`
`f(2) = 40/9 - 10 + 8`
`f(2) = 40/9 - 2`
`f(2) = 40/9 - 18/9 = 22/9`

`f(2) = q/p = 22/9` 입니다. `p=9`, `q=22`는 서로소인 자연수입니다.

### 4. 최종 답

`p+q`의 값을 구하시오.
`p + q = 9 + 22 = 31`

**정답은 31입니다.**
