# MCP 서버 MD 파일 저장 위치 커스터마이징: 프로젝트별 블로그 포스트 관리

## 🎯 문제 상황

MCP 서버를 통해 자동 포스팅할 때 생성되는 MD 파일들이 MCP 서버 폴더 내부에 저장되고 있었습니다. 이는 여러 프로젝트를 관리할 때 불편하고, 프로젝트별 컨텍스트를 유지하기 어려웠습니다.

## 💡 해결책: 사용자 프로젝트에 저장

이제 MD 파일들이 **사용자가 작업 중인 프로젝트 폴더**에 `.codebase_blog/posts` 디렉토리로 저장됩니다!

## 📁 변경 사항

### Before (이전)
```
/mcp-blog-server-ts/
└── posts/
    ├── 20250902_포스트1.md
    └── 20250902_포스트2.md
```

### After (현재)
```
/my-awesome-project/              # 사용자의 프로젝트 폴더
└── .codebase_blog/
    └── posts/
        ├── 20250902_포스트1.md
        └── 20250902_포스트2.md
```

## 🔧 구현 방법

### 1. filesystem.ts 수정

```typescript
export async function savePostToFile(
  title: string,
  body: string,
  tags?: string[]
): Promise<string | null> {
  try {
    // 사용자의 현재 작업 디렉토리 또는 환경 변수에서 경로 가져오기
    const baseDir = process.env['BLOG_POSTS_DIR'] || process.cwd();
    
    // .codebase_blog/posts 디렉토리 생성
    const postsDir = path.join(baseDir, ".codebase_blog", "posts");
    await fs.mkdir(postsDir, { recursive: true });
    
    // 파일 저장...
  }
}
```

### 2. Claude Desktop 설정 방법

#### 옵션 A: cwd를 프로젝트 폴더로 설정 (권장) ⭐

```json
{
  "mcpServers": {
    "my-blog": {
      "command": "node",
      "args": [
        "/path/to/mcp-blog-server-ts/dist/index.js",
        "--transport",
        "stdio"
      ],
      "cwd": "/Users/username/projects/my-project",  // 👈 여기가 핵심!
      "env": {
        "BLOG_API_KEY_ID": "your_key",
        "BLOG_API_KEY_SECRET": "your_secret",

    }
  }
}
```

## 🚀 장점

### 1. **프로젝트별 포스트 관리**
각 프로젝트마다 별도의 `.codebase_blog` 폴더가 생성되어 컨텍스트 유지가 쉽습니다.

### 2. **Git 버전 관리**
프로젝트 저장소에 포함되어 Git으로 버전 관리가 가능합니다.

```bash
# .gitignore에 추가 (원하는 경우)
.codebase_blog/

# 또는 커밋에 포함 (문서화 목적)
git add .codebase_blog/posts/
git commit -m "docs: 블로그 포스트 추가"
```

### 3. **팀 공유 가능**
팀 프로젝트의 경우, 기술 문서나 개발 일지를 팀원들과 공유할 수 있습니다.

### 4. **프로젝트 컨텍스트 유지**
작업 중인 프로젝트와 관련된 포스트들이 한 곳에 모여 있어 관리가 편리합니다.

### 5. **백업 자동화**
프로젝트 백업 시 블로그 포스트도 함께 백업됩니다.

## 🔄 마이그레이션 가이드

기존 사용자가 새 방식으로 전환하려면:

1. **MCP 서버 업데이트**
   ```bash
   cd mcp-blog-server-ts
   git pull
   pnpm build
   ```

2. **Claude Desktop 설정 수정**
   - `cwd` 필드를 현재 작업 중인 프로젝트 폴더로 변경

3. **Claude Desktop 재시작**

4. **완료!** 
   이제 포스트가 프로젝트 폴더에 저장됩니다.
