# 이미지 리사이징 기능 테스트 가이드

## 테스트 절차

### 1. 포스트 작성 페이지 접속
- http://localhost:3001 접속
- 로그인 후 블로그 생성 (없는 경우)
- "새 포스트 작성" 버튼 클릭

### 2. 이미지 업로드 테스트
1. 에디터에서 이미지 아이콘 클릭 또는 드래그&드롭
2. 이미지 업로드 확인

### 3. 이미지 리사이징 테스트
- **드래그 리사이징**: 이미지 우측 하단 핸들 드래그
- **종횡비 유지**: 리사이징 중 종횡비 자동 유지 확인
- **크기 표시**: 선택 시 이미지 크기 표시 확인
- **더블클릭 복원**: 이미지 더블클릭으로 원본 크기 복원

### 4. 확인 사항
✅ 이미지 선택 시 파란색 테두리 표시
✅ 우측 하단 리사이즈 핸들 표시 (파란색 삼각형)
✅ 드래그로 크기 조절 가능
✅ 종횡비 자동 유지
✅ 실시간 크기 표시 (예: 800 × 600)
✅ 더블클릭으로 원본 크기 복원
✅ 최소 크기 100px, 최대 크기 1200px 제한

## 기대 동작

### 시각적 피드백
- 이미지 선택: 파란색 테두리 + 리사이즈 핸들
- 리사이징 중: 커서 변경 (se-resize)
- 크기 정보: 우측 상단에 실시간 표시

### 기능적 동작
- 종횡비 유지하며 리사이징
- 최소/최대 크기 제한
- 더블클릭으로 원본 크기 복원
- 에디터 저장 시 리사이즈된 크기 유지

## 문제 해결

### 리사이즈 핸들이 보이지 않는 경우
- 이미지를 클릭하여 선택 상태 확인
- CSS 파일이 제대로 로드되었는지 확인

### 드래그가 안 되는 경우
- react-resizable 패키지 설치 확인
- 브라우저 콘솔에서 에러 확인

## 구현 세부사항

- **라이브러리**: react-resizable
- **컴포넌트**: ResizableImageNode.tsx
- **스타일**: editor.css
- **통합**: RichTextEditor.tsx의 ResizableImage 확장
