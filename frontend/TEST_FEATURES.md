## 테스트 체크리스트

### 1. 이미지 업로드 기능
- [ ] 이미지 파일 선택하여 업로드
- [ ] 업로드된 이미지가 에디터 본문에 표시되는지 확인
- [ ] "업로드된 이미지" 갤러리에 표시되는지 확인
- [ ] 드래그 앤 드롭으로 이미지 업로드 가능한지 확인

### 2. 이미지 삭제 기능
- [ ] 갤러리 이미지에 X 버튼이 보이는지 확인 (opacity-90으로 항상 표시)
- [ ] X 버튼 호버 시 빨간색이 진해지는지 확인
- [ ] 삭제 시 갤러리와 에디터 모두에서 제거되는지 확인

### 3. 드래그 순서 변경 기능
- [ ] 갤러리에서 이미지 드래그 가능한지 확인
- [ ] 드래그로 순서 변경 시 갤러리 순서 변경 확인
- [ ] **중요**: 순서 변경이 에디터 본문에도 반영되는지 확인
- [ ] 드래그 중 이미지가 반투명(opacity-50)이 되는지 확인

### 4. YouTube 기능
- [ ] YouTube URL 붙여넣기 (예: https://www.youtube.com/watch?v=dQw4w9WgXcQ)
- [ ] 에디터에 YouTube 영상이 임베드되는지 확인
- [ ] **중요**: "업로드된 이미지" 갤러리에 YouTube 썸네일이 표시되는지 확인
- [ ] YouTube 썸네일도 드래그로 순서 변경 가능한지 확인
- [ ] YouTube 썸네일 삭제 가능한지 확인

### 5. 썸네일 선택 기능
- [ ] 갤러리 이미지 클릭 시 썸네일로 선택되는지 확인
- [ ] 선택된 이미지에 "썸네일" 배지가 표시되는지 확인
- [ ] YouTube 썸네일도 선택 가능한지 확인

### 6. 양방향 동기화
- [ ] 에디터에서 이미지 삭제 시 갤러리에서도 제거되는지 확인
- [ ] 갤러리에서 삭제 시 에디터에서도 제거되는지 확인
- [ ] 순서 변경이 양방향으로 동작하는지 확인

## 테스트 시나리오

### 시나리오 1: 복합 작업
1. 이미지 2개 업로드
2. YouTube 링크 1개 붙여넣기
3. 갤러리에서 순서를 YouTube → 이미지1 → 이미지2로 변경
4. 에디터 본문에도 같은 순서로 표시되는지 확인
5. 중간 이미지(이미지1) 삭제
6. 양쪽 모두에서 제거되는지 확인

### 시나리오 2: 썸네일 관리
1. 이미지 3개 업로드
2. 두 번째 이미지를 썸네일로 선택
3. YouTube 링크 추가
4. YouTube 썸네일로 변경
5. 정상 동작하는지 확인
