## 1. 목적

이 약관은 `{{OPERATOR_NAME}}`가 `{{PUBLIC_SITE_URL}}`에서 운영하는 self-host
블로그·커뮤니티 서비스의 이용 조건과 책임 범위를 설명합니다.

## 2. 운영 구조

- 이 소프트웨어는 공개 저장소에서 배포되는 self-host 프로젝트입니다.
- 각 배포본은 해당 인스턴스를 운영하는 사람 또는 조직이 직접 관리합니다.
- 공개 저장소의 원저작자는 사용자의 개별 배포를 운영하지 않으며, 배포자의
  데이터 처리나 계정 운영을 대신하지 않습니다.

## 3. 계정과 인증

- 로그인 제공자, 비밀번호 정책, 관리자 권한 부여, 계정 복구 절차는 운영자가
  설정하고 관리합니다.
- 사용자는 타인의 계정, 토큰, 결제수단, 개인 정보를 무단 사용해서는 안 됩니다.
- 운영자는 보안, 법적 준수, 서비스 안정성을 위해 계정 생성 또는 이용을 제한할
  수 있습니다.

## 4. 사용자 콘텐츠

- 사용자는 자신이 게시하거나 업로드하는 콘텐츠에 대한 권리와 책임을 집니다.
- 사용자는 법령, 계약, 타인의 권리를 침해하는 콘텐츠를 게시해서는 안 됩니다.
- 운영자는 서비스 운영, 백업, 보안 분석, 신고 처리, 악성 콘텐츠 차단을 위해
  필요한 범위에서 콘텐츠를 저장·검토·제한할 수 있습니다.

## 5. 금지 행위

- 불법 콘텐츠 업로드 또는 배포
- 타인 사칭, 계정 탈취, 권한 우회, 자동화 남용
- 악성 스크립트, 피싱, 멀웨어, 스팸, 대량 괴롭힘
- 서비스·네트워크·스토리지·로그인 흐름을 방해하는 행위

## 6. 외부 서비스

- OAuth, SMTP, 객체 저장소, CDN, 분석, 결제, AI 도구 같은 외부 서비스는
  운영자가 별도로 연결할 수 있습니다.
- 외부 서비스 사용으로 발생하는 계약, 과금, 데이터 이전, 장애는 해당 서비스와
  운영자 사이의 책임 범위에 따릅니다.

## 7. 종료와 데이터

- 운영자는 서비스 종료, 정책 변경, 보안 사고, 법적 요구에 따라 계정이나
  콘텐츠를 제한·삭제할 수 있습니다.
- 사용자는 필요한 데이터를 스스로 백업해야 합니다.

## 8. 면책

- 본 서비스와 소프트웨어는 있는 그대로 제공됩니다.
- 운영자와 공개 저장소의 원저작자는 법령이 허용하는 범위에서 특정 목적 적합성,
  무중단 운영, 데이터 완전성, 제3자 서비스 결과를 보증하지 않습니다.
- 사용자의 배포, 운영, 로그인 제공자 설정, 결제·과금 연결, 법적 준수 책임은
  해당 배포 운영자에게 있습니다.
