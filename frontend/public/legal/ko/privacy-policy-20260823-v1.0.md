# 개인정보 처리방침

- 문서 버전: `{{LEGAL_DOCUMENT_VERSION}}`
- 개인정보 처리자: `{{OPERATOR_NAME}}`
- 문의: `{{OPERATOR_CONTACT_EMAIL}}`
- 게시 위치: `{{LEGAL_PRIVACY_URL}}`

## 1. 기본 원칙

이 문서는 `{{PUBLIC_SITE_URL}}`를 운영하는 `{{OPERATOR_NAME}}`가 해당 인스턴스
이용자의 개인정보를 어떻게 처리하는지 설명합니다.

공개 저장소의 원저작자는 사용자의 self-host 배포를 직접 운영하지 않으며,
이 인스턴스의 개인정보 처리자는 아닙니다.

## 2. 수집 가능한 정보

- 회원가입 또는 로그인 시 제공되는 이메일, 사용자명, 인증 제공자 식별자
- 사용자가 직접 작성한 게시글, 댓글, 메시지, 업로드 파일
- 보안 및 운영 목적의 접속 로그, IP 주소, 브라우저 정보, 요청 식별자
- 운영자가 별도 연동한 SMTP, OAuth, 스토리지, 분석, 결제 서비스에서 전달되는
  최소 필요 정보

## 3. 이용 목적

- 계정 인증과 보안
- 게시물·댓글·커뮤니티 기능 제공
- 파일 저장과 전달
- 스팸, 악성 행위, 장애, 오남용 탐지
- 문의 대응, 법적 의무 이행, 서비스 운영

## 4. 보관과 삭제

- 운영자는 서비스 운영 목적에 필요한 기간 동안 정보를 보관합니다.
- 사용자는 운영자가 제공하는 절차에 따라 수정·삭제를 요청할 수 있습니다.
- 로그, 백업, 보안 증적은 별도 보관 주기와 법적 의무에 따라 즉시 삭제되지 않을
  수 있습니다.

## 5. 제3자 제공 및 처리위탁

운영자가 설정한 경우 다음과 같은 외부 서비스가 데이터를 처리할 수 있습니다.

- 로그인 제공자: Google, GitHub, Kakao 등
- 이메일 발송: 운영자가 선택한 SMTP 사업자
- 인프라: 서버 호스팅, 객체 저장소, CDN, 모니터링
- 결제 또는 분석: 운영자가 명시적으로 활성화한 경우에 한함

각 서비스의 세부 정책은 운영자가 별도로 검토하고 공지해야 합니다.

## 6. 이용자 권리

- 본인 정보 열람, 정정, 삭제, 처리 제한 요청
- 선택 동의 철회
- 계정 삭제 요청

권리 행사는 `{{OPERATOR_CONTACT_EMAIL}}`로 문의할 수 있습니다.

## 7. 보안

운영자는 합리적인 보안 조치를 적용해야 하지만, 인터넷 전송과 제3자 서비스에
절대적인 안전을 보장할 수는 없습니다.

## 8. 아동 정보

이 인스턴스는 기본적으로 만 14세 이상 사용자를 대상으로 합니다. 운영자는
자신의 관할 법령에 맞는 연령 정책을 적용해야 합니다.

## 9. 변경
