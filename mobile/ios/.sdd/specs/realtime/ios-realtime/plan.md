# 구현 계획: 실시간 연결

> 백그라운드/재연결/오류 복원까지 포함한 실시간 채널 운영

---

## 개요

소켓 기반 실시간 이벤트 수신을 네이티브 생명주기와 맞춰 설계한다.

---

## 기술 결정

### 결정 1: Socket.IO 클라이언트 + 토큰 갱신 인터셉터 결합

- 기존 백엔드 게이트웨이 인증 정책과 매핑이 용이하고, 이벤트 기반 메시지 확장성 확보.

**근거:** 텍스트/메시지 이벤트 지연이 짧고 폴링 대비 효율.

**대안 검토:**
- SSE: 단순성이 장점이지만 양방향 상호작용이 필요한 경우 제한.
- WebSocket 직접 구현: 유연성은 높으나 인증 재연결 루틴 개발 비용 증가.

---

## 구현 단계

### Phase 1: 연결 관리자

- 실시간 연결 상태(state machine) 정의.
- 앱 foreground/background 전환 훅과 연결 생명주기 연결.

**산출물:**
- [ ] ConnectionManager
- [ ] event routing model

### Phase 2: 인증·재연결 전략

- 연결 전 accessToken 확인, 만료 시 갱신 후 재연결.
- exponential backoff 기반 재시도 적용.

**산출물:**
- [ ] reconnect scheduler
- [ ] refresh-before-connect 정책

### Phase 3: 메시지 안정성/UX

- 중복 제거(dedupe), 오프라인 안내, 새 메시지 배지 반영.
- 비정상 끊김 감지와 사용자 안내.

**산출물:**
- [ ] dedupe key 처리
- [ ] 실시간 상태 배너
