## 1. 계정 생성

### 1-1. 오라클 클라우드 가입

1. ✅ https://www.oracle.com/kr/cloud/free/ 접속
2. ✅ **지금 시작하기** 클릭
3. ✅ 이메일, 비밀번호 입력
4. ✅ 국가 선택: **대한민국**
5. ✅ 홈 리전 선택:
   - **권장**: `ap-chuncheon-1` (춘천)
   - 대안: `ap-seoul-1` (서울)

   ⚠️ **중요**: 홈 리전은 계정 생성 후 변경 불가능합니다!

6. ✅ 결제 정보 입력:
   - 신용카드 또는 체크카드
   - $1 인증 (자동 환불)

7. ✅ 휴대폰 인증 (SMS)
8. ✅ 계정 생성 완료 (이메일 확인)

### 1-2. 콘솔 접속 확인

- 콘솔 주소: https://cloud.oracle.com/
- 우측 상단에 **"Always Free"** 배지 확인
- 좌측 상단 햄버거 메뉴 → 리전 확인 (춘천 또는 서울)

## 2. VCN 생성

### 2-1. VCN 마법사 시작

1. ✅ 콘솔 좌측 햄버거 메뉴 → **네트워킹** → **가상 클라우드 네트워크** 클릭
2. ✅ 좌측 **VCN 마법사 시작** 버튼 클릭
3. ✅ **인터넷 연결을 사용하여 VCN 생성** 선택 → **VCN 마법사 시작** 클릭

### 2-2. VCN 구성

| 항목 | 값 | 설명 |
|------|-----|------|
| **VCN 이름** | `codebase-vcn` | 네트워크 이름 |
| **구획** | `root` (기본값) | 최상위 구획 사용 |
| **VCN IPv4 CIDR 블록** | `10.0.0.0/16` | 65,536개 IP 주소 |
| **퍼블릭 서브넷 IPv4 CIDR** | `10.0.0.0/24` | 256개 IP (VM용) |
| **프라이빗 서브넷 IPv4 CIDR** | `10.0.1.0/24` | 256개 IP (DB용, 미사용) |
| **DNS 도메인 이름** | 기본값 유지 | |

4. ✅ **다음** → **생성** 클릭
5. ✅ 생성 완료 대기 (30초~1분)

### 2-3. 생성 결과 확인

생성 완료 후 자동으로 생성되는 리소스:
- ✅ VCN: `codebase-vcn`
- ✅ 인터넷 게이트웨이 (Internet Gateway)
- ✅ NAT 게이트웨이 (NAT Gateway)
- ✅ 서비스 게이트웨이 (Service Gateway)
- ✅ 라우팅 테이블 2개 (퍼블릭, 프라이빗)
- ✅ 보안 목록 2개 (퍼블릭, 프라이빗)

## 3. 보안 목록 설정

### 3-1. 보안 목록 수정

1. ✅ VCN 상세 페이지 → 좌측 **보안 목록** 클릭
2. ✅ **Default Security List for codebase-vcn** 클릭
3. ✅ **수신 규칙 추가** 버튼 클릭

### 3-2. 수신 규칙 추가

다음 4개 규칙을 **하나씩** 추가합니다:

#### 규칙 1: SSH
| 항목 | 값 |
|------|-----|
| **소스 유형** | CIDR |
| **소스 CIDR** | `0.0.0.0/0` |
| **IP 프로토콜** | TCP |
| **소스 포트 범위** | 빈칸 (All) |
| **대상 포트 범위** | `22` |
| **설명** | SSH Access |

- **다른 수신 규칙 추가** 클릭

#### 규칙 2: HTTP
| 항목 | 값 |
|------|-----|
| **소스 CIDR** | `0.0.0.0/0` |
| **IP 프로토콜** | TCP |
| **대상 포트 범위** | `80` |
| **설명** | HTTP for Certbot |

- **다른 수신 규칙 추가** 클릭

#### 규칙 3: HTTPS
| 항목 | 값 |
|------|-----|
| **소스 CIDR** | `0.0.0.0/0` |
| **IP 프로토콜** | TCP |
| **대상 포트 범위** | `443` |
| **설명** | HTTPS |

- **다른 수신 규칙 추가** 클릭 (선택)

#### 규칙 4: ICMP (Ping, 선택사항)
| 항목 | 값 |
|------|-----|
| **소스 CIDR** | `0.0.0.0/0` |
| **IP 프로토콜** | ICMP |
| **유형 및 코드** | 빈칸 (All ICMP) |
| **설명** | Ping |

4. ✅ **수신 규칙 추가** 클릭 (최종 저장)

### 3-3. 발신 규칙 확인

발신 규칙은 기본값 유지:
- 소스 CIDR: `0.0.0.0/0`
- IP 프로토콜: 모든 프로토콜
- **변경하지 않습니다.**

## 4. Compute Instance 생성

### 4-1. 인스턴스 생성 시작

1. ✅ 콘솔 좌측 햄버거 메뉴 → **컴퓨트** → **인스턴스** 클릭
2. ✅ **인스턴스 생성** 버튼 클릭

### 4-2. 기본 정보 입력

| 항목 | 값 |
|------|-----|
| **이름** | `codebase-prod-vm` |
| **구획** | `root` (기본값) |
| **가용성 도메인** | 자동 선택 (첫 번째) |

### 4-3. 이미지 및 Shape 선택

#### 이미지 변경:
3. ✅ **이미지 및 Shape 편집** 클릭
4. ✅ **이미지 변경** 클릭
5. ✅ **Canonical Ubuntu** 선택
6. ✅ OS 버전: **22.04 Minimal aarch64** (ARM) 선택
7. ✅ **이미지 선택** 클릭

#### Shape 변경:
8. ✅ **Shape 변경** 클릭
9. ✅ Shape 시리즈: **Ampere** 선택
10. ✅ Shape 이름: **VM.Standard.A1.Flex** 선택
11. ✅ OCPU 수: **4** (슬라이더를 최대로)
12. ✅ 메모리 양(GB): **24** (슬라이더를 최대로)
13. ✅ **Shape 선택** 클릭

⚠️ **리소스 부족 오류 발생 시**:
- 가용성 도메인 변경 (AD-1 → AD-2 → AD-3)
- 새벽 시간대 재시도 (02:00~06:00 KST)
- 춘천 리전으로 변경 (서울 → 춘천)

### 4-4. 네트워킹 설정

| 항목 | 값 |
|------|-----|
| **네트워크** | 기본 네트워크 선택 |
| **가상 클라우드 네트워크** | `codebase-vcn` 선택 |
| **서브넷** | `퍼블릭 서브넷-codebase-vcn` 선택 |
| **공용 IPv4 주소** | ✅ **공용 IPv4 주소 할당** 체크 |
| **프라이빗 IPv4 주소** | 자동 할당 (기본값) |

### 4-5. SSH 키 설정

#### 로컬에서 SSH 키 생성:

```bash
# 터미널 열기 (Mac: iTerm2, Windows: PowerShell)

# SSH 키 생성
ssh-keygen -t rsa -b 4096 -f ~/.ssh/oracle_key -C "oracle-vm"

# 엔터 2번 (패스워드 없음)

# 공개 키 출력
cat ~/.ssh/oracle_key.pub
```

#### 오라클 콘솔에 키 등록:

14. ✅ **SSH 키 추가** 섹션에서 **내 공개 키 붙여넣기** 선택
15. ✅ 위에서 출력된 SSH 공개 키 전체 복사 → 붙여넣기

### 4-6. 부트 볼륨 설정

16. ✅ **부트 볼륨** 섹션 → **사용자 정의 부트 볼륨 크기 지정** 선택
17. ✅ 부트 볼륨 크기(GB): **100** 입력
   - 무료 티어: 총 200GB
   - 부트 볼륨: 100GB
   - 블록 볼륨: 100GB (나중에 추가)

### 4-7. 인스턴스 생성

18. ✅ **생성** 버튼 클릭
19. ✅ 프로비저닝 대기 (2~5분)
   - 주황색 아이콘: 프로비저닝 중
   - 녹색 아이콘: 실행 중 (완료)

### 4-8. 인스턴스 정보 기록

인스턴스 상세 페이지에서 다음 정보를 복사하여 메모장에 저장:

| 항목 | 값 (예시) |
|------|-----------|
| **퍼블릭 IP 주소** | `123.456.789.012` |
| **프라이빗 IP 주소** | `10.0.0.x` |
| **사용자 이름** | `ubuntu` |
| **가용성 도메인** | `AD-1` |

## 5. Block Volume 추가

### 5-1. Block Volume 생성

1. ✅ 콘솔 좌측 햄버거 메뉴 → **스토리지** → **블록 볼륨** 클릭
2. ✅ **블록 볼륨 생성** 버튼 클릭

#### 블록 볼륨 설정:

| 항목 | 값 |
|------|-----|
| **이름** | `codebase-data-volume` |
| **크기(GB)** | **100** (나머지 100GB 사용) |
| **성능 수준** | **균형 잡힌** (60 IOPS/GB, 기본값) |
| **가용성 도메인** | VM과 동일 (자동 선택) |
| **구획** | `root` (기본값) |

3. ✅ **블록 볼륨 생성** 클릭
4. ✅ 생성 완료 대기 (30초~1분)

### 5-2. Block Volume을 VM에 연결

5. ✅ 생성된 볼륨 이름 클릭 → 상세 페이지
6. ✅ **연결된 인스턴스** 섹션 → **인스턴스에 연결** 클릭

#### 연결 설정:

| 항목 | 값 |
|------|-----|
| **인스턴스** | `codebase-prod-vm` 선택 |
| **장치 경로** | `/dev/oracleoci/oraclevdb` (기본값) |
| **액세스 유형** | **읽기/쓰기** (기본값) |
| **연결 유형** | **iSCSI** (기본값) |

7. ✅ **연결** 버튼 클릭
8. ✅ 연결 완료 대기 (10~30초)

### 5-3. iSCSI 명령어 복사

9. ✅ 연결 완료 후 **iSCSI 명령 및 정보** 버튼 클릭
10. ✅ **연결** 탭의 명령어 3줄 복사 → 메모장에 저장

예시:
```bash
sudo iscsiadm -m node -o new -T iqn.2015-12.com.oracleiaas:abcd1234...
sudo iscsiadm -m node -o update -T iqn.2015-12.com.oracleiaas:abcd1234... -n node.startup -v automatic
sudo iscsiadm -m node -T iqn.2015-12.com.oracleiaas:abcd1234... -p 169.254.2.2:3260 -l
```

## 📝 트러블슈팅

### 문제 1: Ampere Shape 리소스 부족

**증상**: "Out of capacity for shape VM.Standard.A1.Flex" 오류

**해결 방법**:
1. 가용성 도메인 변경 (AD-1 → AD-2 → AD-3)
2. 새벽 시간대 재시도 (02:00~06:00 KST)
3. 리전 변경 (서울 → 춘천)
4. OCPU 수 줄여서 시도 (4 → 2)

### 문제 2: SSH 접속 실패

**증상**: "Permission denied (publickey)" 오류

**해결 방법**:
```bash
# SSH 키 권한 확인
chmod 600 ~/.ssh/oracle_key

# 접속 재시도
ssh -i ~/.ssh/oracle_key ubuntu@퍼블릭IP
```

### 문제 3: 인터넷 연결 안 됨

**증상**: VM에서 외부 인터넷 접속 불가

**해결 방법**:
1. VCN → 라우팅 테이블 → 퍼블릭 서브넷용 라우팅 테이블 확인
2. 라우팅 규칙 확인: `0.0.0.0/0` → 인터넷 게이트웨이 존재하는지 확인
3. 보안 목록 확인: 발신 규칙 `0.0.0.0/0` 모든 프로토콜 허용 확인
