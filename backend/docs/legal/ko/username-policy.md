# 사용자명 정책

**시행일**: 2025년 10월 19일

---

## 1. 개요

사용자명은 Codebase.blog에서 여러분을 식별하는 고유한 이름입니다. 본 정책은 사용자명 생성 규칙, 금지 사항, 변경 절차 등을 안내합니다.

---

## 2. 사용자명 규칙

### 2.1 형식 요구사항

✅ **허용되는 문자**:
- 영문자 (a-z, A-Z)
- 숫자 (0-9)
- 언더스코어 (_)
- 하이픈 (-)
- 한글 (가-힣)

✅ **길이**:
- **최소**: 3자
- **최대**: 20자

✅ **형식**:
- 영문자 또는 한글로 시작
- 특수문자는 중간에만 사용 가능
- 대소문자 구분 없음 (예: `UserName`과 `username`은 동일)

### 2.2 사용 예시

| 사용자명 | 허용 여부 | 사유 |
|----------|-----------|------|
| john_doe | ✅ 허용 | 올바른 형식 |
| 김철수 | ✅ 허용 | 한글 허용 |
| user-123 | ✅ 허용 | 하이픈 포함 가능 |
| ab | ❌ 거부 | 3자 미만 |
| _john | ❌ 거부 | 특수문자로 시작 |
| john@doe | ❌ 거부 | 허용되지 않는 특수문자 (@) |
| thisisaverylongusername123 | ❌ 거부 | 20자 초과 |

## 3. 금지되는 사용자명

Codebase.blog는 다음과 같은 사용자명을 금지합니다:

### 3.1 사칭 및 혼동

❌ **금지 사항**:
- **Codebase, codebase, admin, moderator, support** 등 공식 계정으로 오인될 수 있는 이름
- **유명인, 브랜드, 조직** 사칭 (예: `elonmusk`, `google`, `bts`)
- **타인의 사용자명**을 모방 (예: `john_doe` → `john__doe`)

⚠️ **예외**: 본인임을 증명할 수 있는 경우 허용

### 3.2 욕설 및 혐오 표현

❌ **금지 사항**:
- 욕설, 비속어
- 성적 표현
- 혐오 발언 (인종, 종교, 성별 등)
- 폭력적 표현

### 3.3 상표권 침해

❌ **금지 사항**:
- 등록된 상표명 무단 사용
- 브랜드명을 도용하는 사용자명

⚠️ **예외**:
- 팬 페이지 등은 명확히 표시 시 허용 (예: `apple_fan`, `bts_lover`)
- 공식 계정은 인증 신청 가능

### 3.4 오해를 유발하는 이름

❌ **금지 사항**:
- 스팸, 봇, 가짜 계정으로 오인될 수 있는 이름
- 서비스 기능명 (예: `settings`, `logout`, `api`)
- 예약어 (reserved keywords)

## 4. 사용자명 변경

### 4.1 변경 절차

1. **설정 접근**: 설정 > 계정 > 사용자명 변경
2. **새 사용자명 입력**: 사용 가능 여부 즉시 확인
3. **변경 확인**: 비밀번호 재입력으로 본인 확인
4. **완료**: 즉시 변경 적용

### 4.2 변경 제한

- **변경 횟수**: **30일에 1회**만 변경 가능
- **이유**: 사용자 혼동 방지 및 악용 차단

⚠️ **주의사항**:
- 사용자명 변경 시 기존 사용자명은 다른 사람이 즉시 사용 가능
- URL도 함께 변경됨 (예: `codebase.blog/@old_name` → `codebase.blog/@new_name`)
- 기존 링크는 30일간 자동 리다이렉트

### 4.3 변경 불가 사유

다음의 경우 사용자명 변경이 제한될 수 있습니다:

- 계정 정지 상태
- 최근 30일 이내 변경 이력
- 법적 분쟁 중인 계정

## 5. 인증 사용자명

### 5.1 인증 배지

공식 계정, 유명인, 브랜드는 인증 배지(✓)를 신청할 수 있습니다.

✅ **신청 자격**:
- 공공 인물, 유명인
- 공식 브랜드, 조직
- 월 평균 10,000명 이상 팔로워 (일반 사용자)

### 5.2 인증 신청

1. **신청서 제출**: 설정 > 인증 신청
2. **증빙 자료**: 신분증, 공식 웹사이트, 소셜 미디어 링크 등
3. **검토**: 14일 이내 검토
4. **승인**: 인증 배지 부여

---

## 6. 사용자명 분쟁

### 6.1 상표권 침해 신고

상표권자는 다음 절차로 신고할 수 있습니다:

1. **신고서 제출**: username@codebase.blog
2. **증빙 자료**: 상표 등록증, 권리 증명 서류
3. **검토**: 7~14일 이내 검토
4. **조치**: 침해 확인 시 사용자명 변경 요구 또는 계정 정지

### 6.2 사칭 신고

사칭 피해를 입은 경우:

1. **신고**: 해당 계정 프로필에서 "신고" 클릭
2. **사유 선택**: "사칭"
3. **증빙 제출**: 본인 확인 자료
4. **조치**: 사칭 확인 시 해당 계정 정지 또는 사용자명 변경

---

## 8. 비활성 사용자명 회수

### 8.1 비활성 기준

다음 조건의 사용자명은 회수될 수 있습니다:

- **2년 이상** 로그인하지 않은 계정
- **게시물 없음** 또는 **3개 이하**
- **팔로워 없음** 또는 **10명 이하**

### 8.2 회수 절차

1. **통지**: 회수 60일 전 이메일 통지
2. **유예기간**: 60일 이내 로그인 시 회수 취소
3. **회수**: 미로그인 시 사용자명 회수
4. **재배정**: 회수된 사용자명은 다른 사용자에게 개방

## 9. URL 및 프로필 링크

### 9.1 프로필 URL

사용자명은 프로필 URL에 사용됩니다:

```
https://codebase.blog/@username
```

### 9.2 블로그 URL

블로그 주소는 별도 슬러그 사용:

```
https://codebase.blog/blog/blog-slug
```

> **참고**: 사용자명 변경 시 프로필 URL만 변경되며, 블로그 슬러그는 독립적으로 관리됩니다.
