# 마크다운 작성 규칙 (MCP 블로그 포스팅용)

## ⚠️ 중요: 코드 블록 내 HTML 태그 사용 금지

### 문제가 되는 경우
```markdown
❌ 잘못된 예시:
```python
html = '<div>내용</div>'  # 이 부분이 실제 HTML로 변환됨!
```
```

### 올바른 작성법
```markdown
✅ 올바른 예시:
```python
html = '[div]내용[/div]'  # 대괄호 사용
# 또는
html = 'div 태그로 내용을 감싸기'  # 설명으로 대체
```
```

## 📋 마크다운 작성 규칙

### 1. 코드 블록 규칙
- **HTML 태그 금지**: `<pre>`, `<div>`, `<code>` 등 HTML 태그를 직접 쓰지 마세요
- **대체 방법**:
  - 대괄호 사용: `[div]` 
  - 이스케이프: `&lt;div&gt;`
  - 주석으로 설명: `# div 태그 사용`

### 2. 특수 문자 처리
- `<`, `>` 기호는 코드 블록 밖에서도 주의
- 수식이나 비교 연산자는 백틱으로 감싸기: `a < b`

### 3. 프론트매터 작성
```yaml
---
title: 제목 (필수)
category: tech|general|etc (선택, 기본: general)
tags: [태그1, 태그2] (선택)
status: draft|published (선택, 기본: draft)
---
```

### 4. 이모지 사용
- UTF-8 이모지 지원: 🚀 ✅ ❌ 💡 📝
- 과도한 사용 자제

### 5. 테이블 작성
```markdown
| 헤더1 | 헤더2 | 헤더3 |
|-------|-------|-------|
| 내용1 | 내용2 | 내용3 |
```
- 구분선 필수 (두 번째 줄)
- 정렬 기호 사용 가능: `:---` (왼쪽), `:---:` (가운데), `---:` (오른쪽)

## 🤖 MCP 서버 자동 처리

MCP 서버가 포스트를 생성할 때 자동으로 처리하는 사항:
1. HTML 태그를 대괄호로 자동 치환
2. 특수 문자 이스케이프
3. 코드 블록 언어 자동 감지

## 🐛 일반적인 문제와 해결

### 문제 1: 코드가 깨져서 보임
**원인**: HTML 태그가 포함된 코드
**해결**: 대괄호나 이스케이프 문자 사용

### 문제 2: 코드 블록이 플레이스홀더로 표시
**원인**: 정규식 매칭 실패
**해결**: 백틱 3개 정확히 사용, 언어 지정

### 문제 3: 글씨가 안 보임
**원인**: 배경색과 글자색이 같음
**해결**: 스타일 명시 (자동 처리됨)
