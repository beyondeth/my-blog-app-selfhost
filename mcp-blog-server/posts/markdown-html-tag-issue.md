# 마크다운 코드 블록 내 HTML 태그 문제와 해결책

블로그 포스팅 시 코드 블록이 깨져서 표시되는 문제를 겪었습니다. 
원인은 **마크다운 파일 자체**에 있었지만, 사용자 입장에서는 프론트엔드 문제로 오인하기 쉬운 이슈였습니다.

## 🔍 문제 상황

### 증상
코드 블록에서 이상한 현상이 발생:
- 코드가 중간에 잘림
- 한 글자만 코드 블록으로 처리됨  
- HTML 태그가 실제로 렌더링됨

### 예시
```python
# 문제가 되는 코드 예시
block_html = f'''
    [pre style="background-color: #1e1e1e;"]
        [code class="language-python"]
            {escaped_code}
        [/code]
    [/pre]
'''
# 위에서 []를 <>로 바꾸면 문제 발생
```

## 🤔 원인 분석

### 근본 원인
**마크다운 코드 블록 내에 HTML 태그가 포함되면**, markdown-to-HTML 변환 과정에서 이를 실제 HTML로 해석해버립니다.

### 변환 과정에서 일어나는 일
1. 마크다운 파서가 코드 블록을 처리
2. 코드 블록 내의 pre, code 등 HTML 태그를 실제 태그로 인식
3. 중첩된 태그 구조가 깨지면서 렌더링 오류 발생

### 사용자 관점의 혼란
- ❌ "프론트엔드 렌더링 문제인가?"
- ❌ "변환 로직에 버그가 있나?"
- ✅ **실제로는 마크다운 작성 방식의 문제**

## 📝 마크다운 작성 규칙

### 1. 코드 블록 내 HTML 태그 처리

#### ❌ 잘못된 방법
파이썬 코드에서 HTML 태그를 직접 쓰면 문제가 발생합니다:
- `html = '<div>내용</div>'` 같은 코드는 실제 HTML로 변환됨

#### ✅ 올바른 방법들

**방법 1: 대괄호 사용**
```python
html = '[div]내용[/div]'  # 안전한 표현
```

**방법 2: 이스케이프 문자**
```python
html = '&lt;div&gt;내용&lt;/div&gt;'  # HTML 엔티티
```

**방법 3: 설명으로 대체**
```python
# div 태그로 내용을 감싸는 코드
html = create_element('div', '내용')
```

## 📋 체크리스트

마크다운 파일 작성 시 확인사항:
