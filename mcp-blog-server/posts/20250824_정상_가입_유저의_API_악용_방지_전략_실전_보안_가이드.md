# 정상 가입 유저의 API 악용 방지 전략: 실전 보안 가이드

## 🎯 핵심 우려: "정상 가입 유저가 API를 악용하면?"

이것은 정말 중요한 포인트입니다! 실제로 모든 서비스가 고민하는 문제죠.

## 🔍 악의적 사용자의 가능한 시나리오

### 악의적 사용자 (정상 가입 후)의 상황
```python
# 악의적 사용자가 가진 것들
my_email = "hacker@email.com"      # ✅ 자기 계정

# 가능한 악용 시도들
1. 스팸 포스팅 도배
2. 악성 콘텐츠 업로드
3. API 과부하 공격
4. 다른 사용자 데이터 접근 시도
```

## 🛡️ 현재 방어 체계 vs 악용 시도

### 1. **스팸 도배 시도**
```python
# 악의적 사용자가 시도
for i in range(1000):
    create_post(f"스팸 {i}", "스팸 내용")
```

**현재 방어:**
```typescript
@Throttle({ limit: 15, ttl: 3600000 })  // 시간당 15개!
```
**결과:** ❌ 16번째부터 차단 (429 에러)

### 2. **다른 사용자 포스트 삭제 시도**
```python
# 악의적 사용자가 다른 사람 포스트 삭제 시도
delete_post(other_user_post_id)
```

**현재 방어:**
```typescript
// 작성자 본인만 삭제 가능!
if (post.author.id !== user.id && user.role !== Role.ADMIN) {
    throw new ForbiddenException('권한이 없습니다');
}
```
**결과:** ❌ 403 Forbidden

### 3. **다른 사용자 블로그에 포스팅 시도**
```typescript
// 자기 블로그만 찾음!
const blog = await this.blogsRepository.findOne({
    where: { userId: user.id }  // ← 본인 블로그만!
});
```
**결과:** ❌ 다른 블로그에 못 씀

## 🚨 추가 보안 강화 방안

### 1. **콘텐츠 필터링 (악성 콘텐츠 차단)**
```typescript
@Injectable()
export class ContentFilterService {
  private bannedWords = ['비속어', '광고', 'spam'];
  private suspiciousPatterns = [
    /bit\.ly/gi,  // 단축 URL
    /\d{3}-\d{4}-\d{4}/g,  // 전화번호
    /<script>/gi,  // 스크립트 태그
  ];

  validateContent(content: string): boolean {
    // 금지어 검사
    for (const word of this.bannedWords) {
      if (content.includes(word)) {
        throw new BadRequestException('부적절한 콘텐츠');
      }
    }
    
    // 의심 패턴 검사 → 관리자 알림
    return true;
  }
}
```

### 3. **이상 행동 감지 시스템**
```typescript
async checkUserBehavior(user: User, action: string) {
  const anomalies = [];
  
  // 1. 짧은 시간에 반복 요청
  if (recentActions > 10) {
    anomalies.push('RAPID_REQUESTS');
  }
  
  // 2. 새벽 시간 대량 활동
  if (hour >= 2 && hour <= 5 && recentActions > 5) {
    anomalies.push('UNUSUAL_TIME_ACTIVITY');
  }
  
  // 3. 동일 콘텐츠 반복
  if (similarPosts > 3) {
    anomalies.push('DUPLICATE_CONTENT');
  }
  
  if (anomalies.length > 0) {
    // 계정 제한 + 관리자 알림
    await this.restrictAccount(user, anomalies);
    throw new ForbiddenException('비정상적인 활동 감지');
  }
}
```

## 🎯 즉시 적용 가능한 보안 강화

```typescript
// 포스트 생성 시 추가 검증
async create(createPostDto: CreatePostDto, user: User) {
  // 스팸 검사
  await this.spamFilter.check(createPostDto);
  
  // 이상 행동 검사
  await this.anomalyDetection.check(user);
  
  // 일일 한도 검사
  await this.rateLimiter.check(user);
  
  // 콘텐츠 필터링
  await this.contentFilter.check(createPostDto.content);
  
  // 정상 처리
  return this.createPost(createPostDto, user);
}
```
