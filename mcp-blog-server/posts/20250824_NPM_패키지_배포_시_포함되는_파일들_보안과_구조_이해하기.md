# NPM 패키지 배포 시 포함되는 파일들: 보안과 구조 이해하기

## 📦 짧은 답변: **일부만 설치됩니다!**

NPM 패키지로 배포하면 **선택한 파일들만** 사용자 컴퓨터에 설치됩니다.

## 📂 실제 설치 경로와 구조

### 1. 사용자가 설치하면 어디에 설치되나?

```bash
# 글로벌 설치 시
npm install -g @your-org/mcp-blog-server

# 설치 경로 (Mac/Linux)
/usr/local/lib/node_modules/@your-org/mcp-blog-server/

# 설치 경로 (Windows)
C:\Users\Username\AppData\Roaming\npm\node_modules\@your-org\mcp-blog-server\
```

### 2. 어떤 파일들이 포함되나?

**`package.json`에서 지정한 파일들만 포함됩니다:**

```json
{
  "name": "@your-org/mcp-blog-server",
  "version": "1.0.0",
  "files": [
    "src/",
    "README.md",
    "LICENSE"
  ]
}
```

## 📊 배포 시 포함/제외되는 파일 비교

### ✅ **포함되는 파일** (사용자가 받는 것)
```
@your-org/mcp-blog-server/
├── src/
│   └── fastmcp_blog_server.py  (핵심 코드)
├── README.md                    (사용 설명서)
├── LICENSE                      (라이선스)
└── package.json                 (패키지 정보)
```

### ❌ **제외되는 파일** (사용자가 못 받는 것)
```
❌ .env                 (당신의 비밀 정보!)
❌ posts/               (당신의 포스트 백업)
❌ .git/                (git 히스토리)
❌ __pycache__/         (Python 캐시)
❌ node_modules/        (의존성 - 사용자가 직접 설치)
```

## 🔒 보안 측면에서 중요한 점

### 1. **환경 변수는 절대 포함 안 됨!**
```bash
# 당신의 .env (절대 배포 안 됨!)
BLOG_EMAIL=your@email.com      ❌
BLOG_PASSWORD=yourpassword     ❌  
BLOG_API_KEY=your-secret-key   ❌
```

### 2. **사용자는 자기 환경 변수 설정**
```bash
# 사용자가 직접 만들어야 함
BLOG_EMAIL=user@email.com      # 사용자 계정
BLOG_PASSWORD=userpassword     # 사용자 비밀번호
BLOG_API_KEY=user-api-key      # 사용자가 발급받은 키
```

## 🚀 실제 NPM 배포 프로세스

### 1. 배포 전 체크
```bash
# 배포될 파일 미리보기
npm pack --dry-run

# 실제로 포함될 파일 목록 확인
tar -tzf your-org-mcp-blog-server-1.0.0.tgz
```

### 2. 배포 명령
```bash
# NPM 로그인
npm login

# 패키지 배포
npm publish --access public
```

### 3. 사용자 설치 과정
```bash
# 사용자가 설치
npm install -g @your-org/mcp-blog-server

# 설치 후 구조
/usr/local/lib/node_modules/@your-org/mcp-blog-server/
├── src/fastmcp_blog_server.py
├── README.md
├── LICENSE
└── package.json
```

## 💡 Python 패키지 (PyPI) 배포 대안

MCP가 Python 기반이므로 PyPI가 더 적합할 수 있습니다:

```python
# setup.py
from setuptools import setup, find_packages

setup(
    name="mcp-blog-server",
    version="1.0.0",
    packages=find_packages(where="src"),
    package_dir={"": "src"},
    install_requires=[
        "fastmcp>=0.1.0",
        "httpx>=0.24.0",
        "python-dotenv>=1.0.0",
    ],
)
```

## 📋 `.npmignore` 파일로 제외할 항목 지정

## 📝 핵심 정리

### Q: 내 폴더 전체가 사용자 컴퓨터에 설치되나?
**A: ❌ 아니요!** 

### 실제로 설치되는 것:
1. **코드 파일** (`fastmcp_blog_server.py`) ✅
2. **설명서** (`README.md`) ✅
3. **라이선스** ✅

### 설치 안 되는 것:
1. **당신의 비밀 정보** (`.env`) ❌
2. **당신의 포스트** (`posts/`) ❌
3. **개발 파일들** (`.git/`, 캐시) ❌

## 🔐 보안은 안전합니다!

- 사용자는 **코드만** 받음
- 사용자가 **자기 계정**으로 설정
- 당신의 **비밀 정보는 안전**

## 🎯 결론

**NPM/PyPI 배포는 안전합니다!**

필요한 파일만 선택적으로 배포되며, 당신의 개인 정보나 데이터는 절대 포함되지 않습니다.

**핵심 포인트:**
- `package.json`의 `files` 필드로 포함할 파일 지정
- `.npmignore`로 제외할 파일 지정
- 환경 변수는 절대 배포되지 않음
- 사용자는 자신의 인증 정보 사용

배포 전 `npm pack --dry-run`으로 꼭 확인하세요! 🎉
