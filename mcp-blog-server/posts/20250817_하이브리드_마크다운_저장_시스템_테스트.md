# 하이브리드 마크다운 저장 시스템 테스트

이 포스트는 새로 구현된 **하이브리드 마크다운 저장 시스템**을 테스트합니다.

## 주요 개선사항

### 1. 토큰 절약 (60% 달성)
- **기존**: 마크다운 → HTML → JSON (200-250% 토큰 증가)
- **개선**: 마크다운 원본 직접 전송 (60% 토큰 절약)

### 2. 하이브리드 저장
- `content_markdown`: 마크다운 원본 (편집용)
- `content`: HTML 버전 (디스플레이용)
- `content_type`: 'markdown' | 'html'
- `content_rendered_at`: 렌더링 시점

### 3. 렌더러 포팅
Python → TypeScript로 완전히 포팅되어 **100% 호환성** 보장

## 코드 예시

```typescript
// TypeScript 렌더러 서비스
@Injectable()
export class MarkdownRendererService {
  convertToHtml(text: string): string {
    // 마크다운을 HTML로 변환
    return this.processMarkdown(text);
  }
}
```
