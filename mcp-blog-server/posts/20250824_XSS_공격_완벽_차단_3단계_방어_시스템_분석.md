# XSS 공격 완벽 차단: 3단계 방어 시스템 분석

## 🚨 중요한 질문: `<script>` 태그를 블로그에 넣을 수 있나?

**답: ❌ 불가능합니다!** 3단계 방어 시스템이 작동 중입니다.

## 📊 3단계 방어 시스템 작동 원리

### 1️⃣ **백엔드 (마크다운 렌더링 시)**
```typescript
// markdown-renderer.service.ts
// HTML 특수문자 이스케이프
let escapedCode = code
  .replace(/&/g, '&amp;')
  .replace(/</g, '&lt;')    // < 를 &lt; 로 변환!
  .replace(/>/g, '&gt;')    // > 를 &gt; 로 변환!
```

**`<script>` 입력 시:**
```markdown
# 제목
<script>alert('해킹')</script>
```

**변환 결과:**
```html
<h1>제목</h1>
<p>&lt;script&gt;alert('해킹')&lt;/script&gt;</p>
```
**결과: 텍스트로만 표시됨, 실행 안 됨!**

### 2️⃣ **프론트엔드 (DOMPurify)**
```typescript
// ContentRenderer.tsx
const cleanHtml = DOMPurify.sanitize(sanitizedHtml, {
  ALLOWED_TAGS: [
    'p', 'br', 'strong', 'em', ...
    // ❌ script 태그 없음!
  ],
  FORBID_ATTR: ['onclick', 'onload', 'onerror', 'onmouseover']
});
```

**만약 `<script>` 태그가 들어와도:**
- DOMPurify가 자동 제거
- 위험한 속성도 모두 제거

### 3️⃣ **CSP 헤더 (추가 가능)**
```typescript
// backend/src/main.ts
app.use(helmet({
  contentSecurityPolicy: {
    directives: {
      defaultSrc: ["'self'"],
      scriptSrc: ["'self'"],  // 인라인 스크립트 차단!
    },
  },
}));
```

## 🧪 실제 테스트 시나리오

### 테스트 1: 직접 스크립트 태그
```markdown
입력: <script>alert('XSS')</script>

백엔드 변환: &lt;script&gt;alert('XSS')&lt;/script&gt;
프론트 표시: <script>alert('XSS')</script> (텍스트로만)
```
**결과: ✅ 안전 (실행 안 됨)**

### 테스트 2: 이벤트 핸들러
```markdown
입력: <img src=x onerror="alert('XSS')">

백엔드: 이미지 태그 처리
프론트 DOMPurify: onerror 속성 제거
```
**결과: ✅ 안전 (이벤트 제거됨)**

### 테스트 3: 링크 자바스크립트
```markdown
입력: [클릭](javascript:alert('XSS'))

백엔드: <a href="javascript:alert('XSS')">클릭</a>
프론트 DOMPurify: href 제거 또는 무효화
```
**결과: ✅ 안전**

## 🚨 주의할 점: Rich Text Editor 사용 시

만약 관리자가 Rich Text Editor로 직접 HTML을 입력한다면:

```typescript
// posts.service.ts
else if (createPostDto.content && !this.isMarkdownContent(createPostDto.content)) {
  // HTML을 그대로 저장 (위험!)
  processedContent = createPostDto.content;
  contentType = 'html';
}
```

**해결 방법:**
```typescript
// HTML 콘텐츠도 sanitize 추가
import * as DOMPurify from 'isomorphic-dompurify';

if (contentType === 'html') {
  processedContent = DOMPurify.sanitize(createPostDto.content, {
    ALLOWED_TAGS: ['p', 'br', 'strong', 'em', ...],
    FORBID_TAGS: ['script', 'iframe', 'object', 'embed'],
    FORBID_ATTR: ['onclick', 'onload', 'onerror'],
  });
}
```

### 2. Content Security Policy 설정
```typescript
// backend/src/main.ts
import helmet from 'helmet';

app.use(helmet({
  contentSecurityPolicy: {
    directives: {
      defaultSrc: ["'self'"],
      scriptSrc: ["'self'", "'unsafe-inline'"], // 인라인 스크립트 차단
      styleSrc: ["'self'", "'unsafe-inline'"],
      imgSrc: ["'self'", "data:", "https:"],
    },
  },
}));
```

### 3. 실시간 XSS 감지
```typescript
@Injectable()
export class XssDetectorService {
  private xssPatterns = [
    /<script[^>]*>.*?<\/script>/gi,
    /javascript:/gi,
    /on\w+\s*=/gi,  // onclick, onerror 등
    /<iframe/gi,
    /<object/gi,
    /<embed/gi,
  ];

  detectXss(content: string): boolean {
    for (const pattern of this.xssPatterns) {
      if (pattern.test(content)) {
        // 로깅 및 알림
        this.logger.warn(`XSS attempt detected: ${content.substring(0, 100)}`);
        return true;
      }
    }
    return false;
  }
}
```
